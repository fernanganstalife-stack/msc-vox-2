# MSC VOXITY V2 — Professional Vocal Processing VST3

MSC VOXITY V2 is a fully functional, highly polished professional vocal processing audio plugin inspired by the iconic MySpace-era pop-punk aesthetics. Built with C++17 and the JUCE framework.

## Features
- **Real-Time Auto-Tune**: Natural and Robotic modes with customizable Key, Scale, Note selector, Retune Speed, and Correction Amount with real-time pitch display.
- **Complete Effect Chain**: Compressor, De-Esser, EQ, Saturation/Distortion, Chorus, Stereo Widener, Reverb, Delay (with FL Studio BPM sync), and Master Mix output.
- **Animated Characters**: Smooth idle animations (blinking, breathing, hair/head movement) and dynamic trigger animations on preset change.
- **Custom Interface Themes**: Fully functional accent color customization saved with plugin state.
- **Real-Time Audio Visualizers**: Spectrum analyzers, gain reduction meters, waveform displays, and stereo image meters driven by real audio analysis.

## Compilation via GitHub Actions
1. Upload this complete project folder to a GitHub repository.
2. Go to the **Actions** tab in your GitHub repository.
3. Select **Build VST3 Windows** and click **Run workflow**.
4. Once completed, download the `MSC_VOXITY_V2_VST3_Windows` artifact.
5. Extract and place the `MSC VOXITY V2.vst3` folder into your VST3 plugin directory (`C:\Program Files\Common Files\VST3`).
6. Open FL Studio, rescan plugins, and enjoy!
